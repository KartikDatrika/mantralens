# APP VISION
Visual rendition of standard hymns in Sanskrit that helps user visualise the meaning underneath the hymn with engaging visuals that are in sync with their chant

# MVP SCOPE
responsive render of webapp that syncs the visuals with user hymn chants
Hymns are static hard coded
Visuals must only appear if the hymn is chanted correctly


# Coding standard for MVP
2 pillars DX and UX with anchoring in Literate Programming
